# 🛂 Zebvo Newswire — Passport Social Media Intelligence Dashboard

A real-time social media scraper that aggregates, categorizes, and analyzes passport-related content from multiple platforms using AI/NLP.

## 🎯 Features

- **Multi-platform scraping**: Reddit, HackerNews, Google News (RSS)
- **AI-powered NLP**: GPT-4o-mini for categorization, summarization, sentiment analysis
- **Gibberish detection**: Filters spam/bot content automatically
- **Semantic clustering**: Groups similar posts using OpenAI embeddings + cosine similarity
- **10-language translation**: English, Hindi, Punjabi, Spanish, French, German, Arabic, Chinese, Russian, Japanese
- **Advanced filters**: Platform, category, sentiment, search
- **CSV export**: Download filtered results
- **Real-time updates**: Cron job runs every 30 minutes
